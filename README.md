# Cleaning Cartel website

Every HTML file here is fully self-contained: photos, font, background and cart are all embedded inside the file.
No assets folder is needed.

## Publish on GitHub Pages
1. Create a new public repository.
2. Add file → Upload files → drag in all the files from this folder → Commit.
3. Settings → Pages → Deploy from a branch → main / (root) → Save.

The site goes live at https://YOUR-USERNAME.github.io/REPO-NAME/

## Before launch
- Replace the placeholder phone number (+91 98765 43210) and email (hello@cleaningcartel.in).
- CS Keyna is a demo font, so buy a web licence before launch.
